\# Team Task Tracker



A small full-stack app for learning cloud deployment.



\- Frontend: React, deployed on Vercel

\- Backend: Node.js / Express, running on AWS ECS Fargate

\- Database: PostgreSQL on AWS RDS

\- Scheduled job: AWS Lambda (Node.js) that builds a daily summary

\- CI/CD: Vercel (frontend) and GitHub Actions (backend and Lambda)
